# 冰霜物语故障复盘与回归清单

> 本文记录首个可玩版中已遇到的用户可见问题、真正根因、修复方式和防再发测试。新游戏应直接复用末尾的发布门禁。

## 处理原则

- 现象和根因分开记录；“看起来像网格”不等于根因就在网格层。
- 状态改动先校验后写入，失败分支必须零写入。
- UI 只在命令成功时关闭或局部刷新；失败只显示原因。
- 渲染引擎对象不存放业务自定义字段，跨帧信息放进 `WeakMap`。
- 每个修复至少有一个可自动重现的用例，并在 Android 真机重跑核心路径。

## 竖条问题的定位过程

1. 先将 48 个网格连续描边改为弱填充/落点，视觉噪声降低，但全屏竖条仍在。
2. 依次隔离 grid、item、fx、snow 和生成器，确认竖条只属于 `itemLayer`。
3. 检查活动 DisplayObject bounds，发现新节点高度从 0 跳到约 16566 px。
4. 对照 Pixi Transform 后确认业务代码写入同名 `_sx/_sy`。
5. 用闭包保存动画起点立即消除竖条；再将所有自定义节点字段迁入 `WeakMap`，防止未来引擎版本出现新冲突。

该过程说明：图形异常应使用“分层隔离 + bounds 数值检查”，不能只靠截图猜 CSS 或网格样式。

## 交易交互契约

```text
点击按钮
  → runActionOnce 拦截重复激活
  → GameState 完成全部前置校验
      → 失败 ActionResult: 零写入 + 弹窗不动 + toast
      → 成功 ActionResult: 一次状态提交 + 局部刷新/关闭
```

已迁移的命令：商店宝箱、生成器、体力瓶、宝箱加速/开启、融冰、订单刷新和订单交付。

## 当前发布门禁

- 核心包：4 项 Node 单测。
- 多语言：21 项结构/占位符安全检查 + 12 项 ChatGPT 审校门禁，覆盖英日韩完整配置、漏翻、串语种、术语及工程用语。
- 游戏逻辑：163 项，包含前三章爽感/来源寻路、请求生命周期/旧档迁移、四语 864 条语音资产、失败交易原子性、六章 24 节点通关和选择存档过滤。
- 语音运行时：5 项移动端队列回归 + 2 项生成工具回归（含 venv 解释器路径）；全量资源另由 `voice:verify` 做 864 项媒体检查。
- Android 资源同步：5 项，覆盖空目录启动、引擎运行时及开发文件排除。
- Android 构建配置：36 项，锁定官方源优先、镜像回退、四语资源清单、更新容量以及 Web / Android v0.3 版本一致性。
- 游戏浏览器：10 条 E2E，覆盖安全区、爽玩按钮、任务架、软键盘可见区、剧情内教学、材料寻路、有声序章、渲染 bounds、失败交互和关键剧情演出。
- 下载站：桌面/移动两条 E2E。
- Android：单测、lint、debug/release 构建、APK 签名校验，再做目标真机安装和玩法冒烟。
