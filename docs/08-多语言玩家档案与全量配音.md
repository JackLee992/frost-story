# 多语言、玩家档案与全量配音

## 产品契约

- 游戏语言与配音语言是两个独立设置。新玩家首次默认一致，之后分别保存；修改配音不重载、不改字幕。
- 支持简体中文 `zh-CN`、英文 `en`、日文 `ja`、韩文 `ko`。未支持的 locale 回退到简体中文。
- 昵称在序章剧情中由啾可询问，不是冷启动表单；后续对白、手账及设置中使用同一档案。
- 昵称限 1–12 个 Unicode 字符，会做 NFKC 规范化、压缩空白，拒绝控制字符及 HTML/模板边界符号。昵称只写入本地游戏存档。

## 文本资源

中文源文件是唯一权威版：

```text
web/config/{story,npcs,items,shop,balance,ui}.json
```

其他语言位于：

```text
web/config/locales/{en,ja,ko}/
```

`tools/i18n/generate_locales.py` 只翻译面向玩家的字符串，数值、章节 ID、物品 ID、图片、BGM 和语音 ID 原样复制。翻译前后必须保留 `{{playerName}}` 等占位符及 `<br>` 标记。每种语言有本地增量缓存，新增文案时不必重翻全库；同一语言中途更换模型时必须加 `--force`，避免把两种模型的口吻混在同一套文案中。

```bash
python3 tools/i18n/generate_locales.py --locale en --model gemma4:12b
python3 tools/i18n/generate_locales.py --locale ja --model gemma4:12b
python3 tools/i18n/generate_locales.py --locale ko --model gemma4:12b
npm run test:i18n
```

本地模型输出只是初稿，接下来必须由 ChatGPT 做第二遍审校：统一世界观术语和人名，纠正角色性别、年龄与语气，清理漏翻和工程术语，再人工精修全局 UI 及前三章。定稿写入 `tools/i18n/reviewed/{en,ja,ko}.json` 覆盖层，不直接改模型缓存；这样以后增量翻译不会覆盖已审定文案。`test/i18n.test.js` 会逐文件检查字段树、数组长度、全部数值、不可变 ID、对白说话人、占位符和 HTML 标记；`test/i18n-quality.test.js` 会拦截其他语种字符残留、整句漏翻、人名/术语漂移和生硬工程用语。自动门禁通过也不等于文案定稿；发布前仍要用 360px 宽真实界面审校节奏、口吻和按钮长度。

## 配音资源

脚本中每句可见对白使用稳定 `voiceId`。含动态昵称的台词额外声明不含占位符的 `spoken`，字幕仍显示玩家名称，预录音频则使用自然的泛称。

```text
web/assets/audio/voice/zh/<voiceId>.ogg
web/assets/audio/voice/en/<voiceId>.ogg
web/assets/audio/voice/ja/<voiceId>.ogg
web/assets/audio/voice/ko/<voiceId>.ogg
```

每种语言 216 条：179 条序章/档案/章节/主线/结局对白，15 条村民登场、请求与答谢，22 条啾可教学、反馈和缺料引导；四语共 864 条。中、英、日使用 Kokoro 的原生语种声线，韩语使用 MeloTTS-Korean，并用克制的保时长音高差区分年轻、成年与年长角色。不克隆真人声线。

```bash
npm run voice:manifest
python3 tools/voice/generate_all.py
npm run voice:verify
```

生成器会把 WAV 统一做 65Hz 高通、-16 LUFS / -1.5 dBTP 响度归一化，最终编码为 48kHz、单声道、48kbps Opus。验证脚本会检查 864 条数量和语种完整性、路径唯一、无待替换占位符、Ogg 头、Opus 编码、48kHz 单声道、时长和单文件上限。

批量任务中断后可直接重跑：只有 Ogg 头、大小及修改时间均证明它属于当前 `voice-manifest.json` 的文件才会跳过。翻译、角色声线或语速变化后先重建 manifest，旧音频因早于新清单会自动重生；需要无条件重建时再加 `--force`。MeloTTS 的虚拟环境解释器路径不得做 realpath/`resolve()`，否则符号链接会绕过 venv 并丢失其 Python 依赖，该约束由 `test/voice_generator_test.py` 固定。

## 运行时与存档

- `Config.load()` 根据游戏语言选择配置目录；`Config.voiceUrl()` 只根据配音语言选择音频目录。
- `froststory.locale.v1` 保存启动前就要知道的界面语言；`froststory.save.v1.settings.voiceLanguage` 独立保存配音语言。
- 旧存档没有 `voiceLanguage` 时，迁移为当前游戏语言；旧存档没有昵称时，下次进入会播放补建档案的短剧情，不重置已有进度。
- 配音在首次手势前遭浏览器拒绝时，保留原句到 `pendingVoice`，音频解锁后重试；文件缺失或损坏才跳到队列下一句。

## 动态更新容量

四套离线配音使文件数超过旧版 512 限制。Android 仍保留有界防护，但配额调整为：压缩包 128 MiB、解压后 160 MiB、最多 2048 个文件、单文件 16 MiB。打包脚本与 Android 下载器使用同一压缩包上限，同时仍校验 HTTPS 白名单、声明大小、SHA-256、ZIP 路径和 staging 原子切换。生成流程另外写出 `web/assets/audio/voice/manifest.json`；动态内容只有在中英日韩配置全部存在，且该清单中四语各 216 条 Ogg 逐项通过路径、去重、大小和文件头检查后才能激活。
