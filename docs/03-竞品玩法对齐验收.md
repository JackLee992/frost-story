# 《冰霜物语》v0.1 竞品玩法对齐验收

对标对象为 `Frost Valley™ Merge & Story` v1.8.20。结论基于已授权取得的 APK/XAPK 静态拆解：IL2CPP 元数据、YooAsset 目录和资源命名。目标是复刻其**通用核心玩法循环**，不复制受版权保护的美术、对白、角色或关卡表达。

## 核心循环结论

`点生成器 → 产出材料 → 两个同族同级物品拖拽合并 → 凑齐顶部订单 → 交付得金币/经验 → 扩棋盘与升级 → 消耗材料推进剧情重建`

v0.1 已把这一循环做成可连续操作的首局流程，并用真实触控 E2E 贯通。首单固定需要冰晶 2 级，玩家用开局的两枚 1 级冰晶即可完成第一次合并并立即交付，避免随机订单卡住教学。

## v0.1 明确不冒充对齐的外围系统

- 仓库扩容、云存档、账号同步。
- 激励广告、插屏广告、IAP 和归因 SDK。
- Battle Pass、锦标赛、签到、每日/每周任务及大量限时活动。
- 服务端运营数值和竞品的 ONNX/DDA 动态难度模型。
- Spine 角色动画、换装以及剧情桥接小游戏。

这些内容不影响 v0.1 的合并主循环和前三章试玩，但属于后续版本范围。完整商业化产品不能等同于本次垂直切片。

## 自动化验收映射

- `test/logic.test.js`：生成、合并、订单、升级、宝箱、解锁、爽玩模式、损坏存档、三章九节点和确定性首局闭环。
- `test/e2e.spec.js`：真实指针/触控事件贯通六步教学，并验证挖孔安全区、弹窗边界、爽玩按钮吸边及重启持久化。
- `test/site.spec.js`：下载页在手机/桌面视口下的 APK 下载入口和动态版本信息。

每次发包前必须重新执行上述测试、Android Lint、APK 签名校验和至少一台 ARM64 真机安装启动测试。
