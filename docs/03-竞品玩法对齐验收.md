# 《冰霜物语》v0.3 竞品玩法与叙事互动对齐验收

对标对象为 `Frost Valley™ Merge & Story` v1.8.20。结论基于已授权取得的 APK/XAPK 静态拆解：IL2CPP 元数据、YooAsset 目录和资源命名。目标是复刻其**通用核心玩法循环**，不复制受版权保护的美术、对白、角色或关卡表达。

## 核心循环结论

`点生成器 → 产出材料 → 两个同族同级物品拖拽合并 → 听村民说明并接受请求 → 凑齐材料 → 交付得金币/经验与角色回应 → 扩棋盘与升级 → 推进剧情重建`

v0.3 保留已验证的六章循环，并针对“前三章不够爽、缺料不知道做什么”增加十级冲刺、开局四连、发现/连击奖励、剧情生成器链和情境式材料寻路。

## v0.3 明确不冒充对齐的外围系统

- 仓库扩容、云存档、账号同步。
- 激励广告、插屏广告、IAP 和归因 SDK。
- Battle Pass、锦标赛、签到、每日/每周任务及大量限时活动。
- 服务端运营数值和竞品的 ONNX/DDA 动态难度模型。
- Spine 角色动画、换装以及剧情桥接小游戏。

这些内容不影响 v0.3 的合并主循环与六章试玩，但属于后续版本范围。当前的剧情互动集中在前三章，第 4–6 章仍需增加手势多样性、角色表情和真正改变场景图层的装修结果。完整商业化产品不能等同于本次垂直切片。
